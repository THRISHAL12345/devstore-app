    Search

    Type a name, a tag, or "alternatives to redis". Results explain why they match, and say plainly when a tool doesn't run natively on Windows.

  2. 02

    Read the plan

    See exactly what will run: the WinGet package, version, installer host, hash, license terms, and the exact command. Nothing hidden, nothing silent.

    Install & verify

    DevStore runs the plan, streams the log, then checks the tool is really there. Partial results are reported as partial, never as success.

05 // faq

Questions, answered.

Where do the tools come from?

From WinGet, Microsoft's package manager built into Windows 10 and 11. DevStore shows the exact package and download location before anything installs, and WinGet checks each installer's hash against its manifest.

Does DevStore need administrator rights?

No. DevStore installs and runs as your user. Some tools' own installers ask for admin rights through a normal Windows prompt. The plan tells you when that may happen, and you can always decline.

Will it change tools I already installed?

Only when you choose to update or uninstall them, and the plan warns you when a tool wasn't installed through DevStore.

How does DevStore update itself?

At launch it checks for a newer release and shows a card in Settings. Click Install and it downloads the update, verifies its signature, and restarts. You can turn the check off.

What does DevStore collect about me?

Nothing. No account, no telemetry. It only contacts GitHub to check for its own updates (you can turn that off) and when you ask for GitHub details.

What do I need?

Windows 10 or 11 on an x64 PC. WinGet (the "App Installer" app) is needed to install tools; it's preinstalled on current Windows versions.

How do I uninstall DevStore?

Windows Settings → Apps → Installed apps → DevStore → Uninstall. Tools you installed with DevStore stay installed.
