# DevStore

**The app store for developer tools on Windows.** Find the tool you need, see exactly where it
comes from, and install it with one clear action.

## Download

**[Download DevStore for Windows](https://github.com/THRISHAL12345/devstore-app/releases/latest/download/DevStore-Setup-x64.exe)**
· [Website](https://thrishal12345.github.io/devstore-app/) · [All releases](https://github.com/THRISHAL12345/devstore-app/releases)

1. Download `DevStore-Setup-x64.exe` and open it. It installs for your user account, with no
   administrator prompt.
2. If Windows SmartScreen says "Windows protected your PC", choose **More info → Run anyway**
   (the installer is not code-signed yet). Each release lists the SHA-256 checksum.
3. DevStore updates itself: it checks for new versions at startup and installs them after you
   confirm.

Requires Windows 10 or 11 (x64).
